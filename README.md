# Gestión de Versiones de un Proyecto de Software

## Descripción del caso práctico

Una empresa de desarrollo de software necesita organizar los archivos de sus proyectos y mantener un historial de los cambios realizados. Para solucionar esta situación, se utilizará Git y GitHub, herramientas que permiten controlar las versiones, registrar modificaciones y trabajar mediante ramas.

## Objetivo del repositorio

Implementar un repositorio público que permita organizar los archivos de un proyecto, registrar los cambios mediante commits, utilizar ramas de desarrollo y gestionar la integración de modificaciones mediante una pull request.
